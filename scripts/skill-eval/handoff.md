# Evaluation integration

Use the protocol and commands in [README.md](README.md). Semantic grading is version 3 and promotion policy is version 2; the outer report remains version 1 for reading compatibility. Legacy reports cannot promote. Reconciliation imports the same `validatePromotionEvidence` gate.

Both editor clients consume the same Node CLI. Keep real source evidence, guidance snapshots and results private. Runtime execution must use explicit supported model/effort pins; it never changes user defaults. Collector and scheduling behavior are unchanged. Optimizer experiments need their own approved scope and budget.
